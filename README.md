## 特徴
IScript BrowserExrension とは、IScriptをChrome/Edge/Firefoxで動作させるためのインタプリタです。
## 特有の仕様
このブランチは、Chrome向け(c)です。
- Manifest v3
- IScriptv1.0に準拠

## IScriptとは
IScript はシンプルで直感的な、ブラウザ向けのスクリプト言語です。<br>
学習コストが低く、簡潔な文法であり、軽い用途での使用を想定しています。

### 理念
「シンプル」「直観的」「高い移植性」「低い開発コスト」をコンセプトに開発されています。<br>
抽象化されたすべての命令・文法は、後方互換性を保証されています。

### 特徴
- 初心者でも読みやすい構文
- シンプルで直感的
- 各種プラットフォームでの実行
- 後方互換性を保証

構文については、[公式ドキュメント](https://abatbeliever.net/docs/IScript/)を参照ください。
